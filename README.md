I'm a developer who likes understanding *why* things work, not just making them run. Right now I'm working on a **freelance project for SBECO** alongside a friend, learning **Machine Learning** from the ground up, and practicing **Data Structures & Algorithms** consistently to get better at breaking problems down.

I enjoy working in **Python** for data analysis (Pandas, NumPy, Matplotlib, Seaborn) and in **React + Tailwind CSS** for building clean interfaces. My interests sit where **software engineering, AI, and data science** overlap — especially applications that solve meaningful real-world problems.

I also took part in a **NASA Hackathon**, where my team built an **LLM-based application that analyzes global carbon emissions** and surfaces insights about worldwide environmental impact.
