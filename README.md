### Namaste, I'm Divyam.

I'm a developer who likes understanding *why* things work, not just making them run. At the moment, I'm working on a freelance project for **SBECO** alongside a friend, learning **Machine Learning**, and practising **Data Structures & Algorithms**.

I enjoy moving between Python and React — exploring datasets, building interfaces, and experimenting with ideas that can turn into useful applications. I'm especially interested in the overlap between software engineering, AI, and data science.

I also participated in a **NASA Hackathon**, where my team built an LLM-based application to analyse global carbon emissions and surface insights about environmental impact.
